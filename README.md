# Watchlist

Movies and web series, published from an Obsidian folder: https://knowjoby.github.io/watchlist/

`publish.py` publishes allow-listed frontmatter fields (title, type, platform, date, minutes, progress, episodes, poster URL; plus year, status, rating, take from hand-made notes)
from ObsidianCapture's Media Log (Series and Movie only) and the `🎬 Watchlist` folder. Never note bodies, URLs or IDs.
A hand-made note with `publish: false` and a matching title hides an auto-captured title. `--dry-run` previews.
